# Настройка AI из веб-интерфейса

## 🎯 Новые возможности

### 1. Настройка AI моделей из UI
Теперь вы можете настраивать AI модели прямо из веб-интерфейса без необходимости редактировать `.env` файлы.

**Как использовать:**
1. Перейдите в раздел **"Настройки AI"** в боковом меню
2. Выберите нужную модель (OpenAI, Anthropic, DeepSeek, OpenRouter, YandexGPT, GigaChat)
3. Включите модель переключателем
4. Введите API ключ
5. Выберите модель (например, `gpt-4-turbo-preview`)
6. Нажмите **"Тест подключения"** для проверки
7. Нажмите **"Сохранить"**

Настройки сохраняются в `localStorage` браузера и доступны на странице AI рерайта.

### 2. Разделённый просмотр (Split View)
Страница AI рерайта теперь показывает **два окна рядом**:

**Левое окно — Оригинал (ДО обработки):**
- Текст новости из источника
- Можно редактировать перед рерайтом
- Кнопка копирования оригинала

**Правое окно — Результат (ПОСЛЕ обработки):**
- Текст после AI рерайта
- Можно редактировать результат
- Кнопка копирования результата
- Кнопка "В модерацию" для отправки на проверку

### 3. Ручной запуск рерайта
Рерайт больше не запускается автоматически. Теперь вы:

1. Выбираете новость из списка
2. Выбираете AI модель и стиль
3. Настраиваете параметры (temperature, max tokens)
4. Нажимаете **"Запустить рерайт"**
5. Наблюдаете прогресс генерации в реальном времени
6. Редактируете результат при необходимости
7. Отправляете на модерацию или переписываете заново

### 4. Прогресс-бар генерации
Во время генерации текста отображается:
- Анимация загрузки
- Процент выполнения (0-100%)
- Прогресс-бар с градиентом
- Частичный результат появляется по мере генерации

## 📋 Пошаговая инструкция

### Шаг 1: Настройка AI моделей

1. Откройте **"Настройки AI"** в меню
2. Выберите модель, которую хотите использовать
3. Включите её переключателем
4. Получите API ключ:
   - **OpenAI**: https://platform.openai.com/api-keys
   - **Anthropic**: https://console.anthropic.com/settings/keys
   - **DeepSeek**: https://platform.deepseek.com/api_keys
   - **OpenRouter**: https://openrouter.ai/keys (мин. $5)
   - **YandexGPT**: https://console.cloud.yandex.ru/
   - **GigaChat**: https://developers.sber.ru/studio/workspaces
5. Вставьте API ключ в поле
6. Выберите модель из списка или введите название вручную
7. Нажмите **"Тест подключения"**
8. Если тест успешен — нажмите **"Сохранить"**

### Шаг 2: Запуск рерайта

1. Перейдите в раздел **"AI Рерайт"**
2. Нажмите **"Настройки AI"** (кнопка в правом верхнем углу) для быстрой настройки
3. Выберите новость из списка справа
4. В левом окне появится оригинальный текст
5. При необходимости отредактируйте оригинал
6. Выберите стиль рерайта:
   - 📰 **Информативный** — чётко и по делу
   - 🔥 **Вовлекающий** — эмоции и CTA
   - 🔍 **Аналитический** — глубокий разбор
   - 💬 **Разговорный** — простой язык
   - 💼 **Профессиональный** — деловой стиль
7. Настройте параметры:
   - **Temperature** (0-1): выше = креативнее, ниже = точнее
   - **Max tokens**: максимальная длина результата
   - **Дополнительный промпт**: особые инструкции для AI
8. Нажмите **"Запустить рерайт"**
9. Дождитесь завершения генерации (прогресс-бар)
10. Отредактируйте результат при необходимости
11. Нажмите **"В модерацию"** для отправки на проверку

### Шаг 3: Сравнение результатов

Используйте разделённый просмотр для:
- Сравнения оригинала и результата
- Проверки, что AI не добавил лишних фактов
- Редактирования обоих текстов
- Копирования нужной версии

## 🔧 Технические детали

### Хранение настроек
Настройки AI сохраняются в `localStorage` браузера:
```javascript
localStorage.getItem('ai-providers-config')
```

Структура данных:
```typescript
interface AIProviderConfig {
  id: string;           // 'openai', 'anthropic', etc.
  name: string;         // 'OpenAI', 'Anthropic', etc.
  icon: string;         // Эмодзи иконка
  apiKey: string;       // API ключ
  model: string;        // Название модели
  enabled: boolean;     // Включена ли модель
  baseUrl?: string;     // Base URL API
}
```

### Интеграция с backend
В production версии настройте backend API endpoint:
```typescript
// В src/pages/AIRewrite.tsx
const response = await fetch('/api/ai/rewrite', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    text: originalText,
    provider: selectedModel,
    style: selectedStyle,
    options: { temperature, maxTokens, customPrompt }
  })
});
```

Backend должен:
1. Получить настройки из БД или `.env`
2. Вызвать соответствующий AI API
3. Вернуть результат рерайта
4. Записать использование в `ai_usage` таблицу

### Безопасность API ключей
⚠️ **Важно:** В текущей версии API ключи хранятся в `localStorage` браузера. Для production:

1. Храните ключи только на backend
2. Frontend отправляет запросы на backend
3. Backend подставляет ключи и вызывает AI API
4. Ключи никогда не покидают сервер

## 💡 Советы по использованию

### Выбор модели
- **DeepSeek V3** — лучший баланс цена/качество (в 100 раз дешевле GPT-4)
- **GPT-4** — максимальное качество для важных публикаций
- **Claude 3 Opus** — отличный для аналитических текстов
- **OpenRouter** — гибкость и автоматический fallback

### Выбор стиля
- **Информативный** — для срочных новостей
- **Вовлекающий** — для популярных тем
- **Аналитический** — для сложных событий
- **Разговорный** — для лёгкого контента
- **Профессиональный** — для деловой аудитории

### Параметры генерации
- **Temperature 0.3-0.5** — для точных фактов
- **Temperature 0.7** — баланс креативности и точности
- **Temperature 0.9-1.0** — для креативных текстов
- **Max tokens 500-1000** — оптимальная длина поста

### Экономия бюджета
1. Используйте DeepSeek для большинства задач
2. Кэшируйте результаты одинаковых запросов
3. Ограничьте max tokens до необходимого минимума
4. Используйте батчинг для массового рерайта

## 🐛 Решение проблем

### "Настройте API ключ"
**Проблема:** Кнопка "Запустить рерайт" неактивна

**Решение:**
1. Перейдите в "Настройки AI"
2. Включите нужную модель
3. Введите API ключ
4. Нажмите "Сохранить"
5. Вернитесь в "AI Рерайт"

### "Ошибка подключения"
**Проблема:** Тест подключения не проходит

**Решение:**
1. Проверьте правильность API ключа
2. Убедитесь, что на балансе есть средства
3. Проверьте Base URL (должен соответствовать провайдеру)
4. Проверьте интернет-соединение

### Результат содержит выдуманные факты
**Проблема:** AI добавил информацию, которой не было в оригинале

**Решение:**
1. Уменьшите temperature (0.3-0.5)
2. Добавьте в промпт: "Используй только факты из оригинала"
3. Внимательно проверяйте результат перед публикацией
4. Используйте аналитический стиль для более точных результатов

### Медленная генерация
**Проблема:** Рерайт занимает слишком много времени

**Решение:**
1. Уменьшите max tokens
2. Используйте более быструю модель (GPT-3.5, DeepSeek V3)
3. Проверьте интернет-соединение
4. Убедитесь, что API не перегружен

## 📊 Мониторинг использования

В backend реализована таблица `ai_usage` для отслеживания:
- Какой провайдер и модель использовались
- Количество входных/выходных токенов
- Стоимость запроса
- Время выполнения (latency)
- Успешность запроса
- Ошибки

Просмотр статистики:
```sql
SELECT 
  provider,
  model,
  COUNT(*) as requests,
  SUM(input_tokens + output_tokens) as total_tokens,
  SUM(cost) as total_cost,
  AVG(latency) as avg_latency
FROM ai_usage
WHERE created_at >= NOW() - INTERVAL '7 days'
GROUP BY provider, model
ORDER BY total_cost DESC;
```
